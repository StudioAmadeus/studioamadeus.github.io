# THE QUARTERLY CLOSE — the EXPO almanac

**In plain words:** every three months, the trading machine writes its own
report card. Not "how much money it made" — at this size that number is
mostly noise — but the things a careful reader can actually learn from:

- **What died.** The machine constantly proposes precise trading rules and
  tests each one against years of real price history. Almost all of them
  fail the test. Each issue lists the failures and the reason each one died.
- **The rising bar.** Every attempt ever made raises the score the next
  idea must beat — because if you test enough ideas, some look brilliant by
  pure luck. The bar is the defense against fooling ourselves, and its
  current height prints in every issue.
- **What trading actually costs.** Fees, spread, slippage — measured from
  real quotes at small size, not estimated.
- **Verdicts, with receipts.** When a strategy is judged, the judgment
  prints alongside a fingerprint (a hash) of the exact rules that governed
  it — so the record can be checked later without revealing anything
  private.
- **The market's weather.** Each period gets a simple label — trending,
  choppy, or violent — computed by fixed, published arithmetic.
- **One lesson.** A short note from the machine's own teaching library,
  quoted word for word.

The rules it is printed under:

- **A ledger close, not an editorial deadline.** Issues print at calendar
  quarter closes. An empty quarter prints as an empty quarter — flat is a
  position for the publication too.
- **Immutable once published.** Corrections print as errata in the next
  issue, never edits.
- **Fixed template, every issue,** in the same order, so issues can be
  compared honestly across years. No quiet redefinitions of any number.
- **Educational, never advisory.** The issue reports what died, what it
  cost, and what was measured — it never recommends anything.
- **Free.** The record of failures is free forever.
